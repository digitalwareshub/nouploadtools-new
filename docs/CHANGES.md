# Changes

## 2026-10-03 — Submission abuse hardening and contact privacy

- Started from current main / deployed commit `fe4ce2d`.
- Added atomic Upstash rolling limits of 5 verified attempts per hour and 10 per 24 hours. Field validation and Turnstile run before quota consumption; blocked requests consume no quota. Duplicates/database failures after verification count as attempts. Missing protection configuration or Redis failure returns a friendly 503; quota exhaustion returns 429 with Retry-After.
- Derive a server-side HMAC-SHA256 source fingerprint from the Vercel request IP with a private `SUBMISSION_FINGERPRINT_SECRET` (at least 32 random characters). No raw IP, browser/user-agent fingerprint, cookies, or extra tracking are stored by the submission protection.
- Save pending tools and a server-only abuse log atomically through a service-role-only, SECURITY INVOKER RPC. The log contains only tool ID, fingerprint, domain, timestamp, and `submitted` outcome. RLS is enabled; PUBLIC/anon/authenticated have no table or RPC access.
- Added a small existing-review-row warning at 3+ successful submissions from the same source in the rolling last 24 hours; it is informational, not an automatic spam verdict. Only counts reach admin HTML, not fingerprints. Older submissions cannot be backfilled because their source was never recorded.
- Restrict public tools SELECT to explicit directory columns, excluding submitted_by_email and submitted_by_name. Public reads, homepage/SEO/directory props, and featured tool choices request that projection. Admin service-role access to contact fields remains available. Direct browser INSERT stays revoked.
- Validate Siteverify success strictly, action, and an exact hostname allowlist (`TURNSTILE_ALLOWED_HOSTNAMES`, with production host defaults); handle null/non-object JSON and database network/timeout errors cleanly. Error logs no longer include database response bodies or network exception details.
- Show a clear security retry state when the Turnstile script errors or fails to become ready within 15 seconds. Existing widget expiry/reset behavior is preserved.
- Document submission abuse processing in the privacy policy and new environment expectations in .env.example.
- Removed an unused submission state and changed the featured form's existing /submit anchor to Next Link to satisfy the required zero-warning lint check.
- Added dependency-free Node tests using the existing TypeScript compiler, plus real Redis script checks (requires redis-server and redis-cli). Tests cover invalid requests/tokens, hostname/action mismatch, outage behavior, safe fingerprints, quota ordering, rolling boundaries, concurrent admission, public projection, and admin count fetching.

- Corrected source extraction for the actual Cloudflare → Vercel hosting path: accept CF-Connecting-IP only when the Vercel-provided peer falls within Cloudflare's published IPv4/IPv6 proxy ranges. Direct Vercel clients cannot spoof that header; missing visitor headers behind a verified proxy fail closed. Tests confirm unrelated visitors do not share a proxy quota.
- Preserved the existing slug trigger through an explicit `pg_catalog, public` search path on the new service-only insert RPC; browser roles cannot CREATE in public.

Production rollout: private abuse-log/RPC and contact-field migrations applied; new HMAC secrets configured on Vercel Production and Preview. Final application deployment: https://nouploadtools-8ph7i4zoq-digiwares.vercel.app (promoted to https://nouploadtools.com). Deployment was performed directly from the working folder before the Git commit. Application changes, tests, and all three already-applied database migrations are recorded together in the repository; the migrations do not need to be reapplied to production.

- Aligned the three local submission-hardening migration filenames and ordering with the versions already recorded in the production Supabase migration ledger. The SQL content was verified against the applied statements; this is repository-history repair only and makes no production schema change.
